# Database – Common Templates

## Overview
This project contains a collection of reusable SQL templates and examples designed for PostgreSQL databases.

## Purpose
The goal is to provide a centralized reference for common SQL scripts, database structures, and query examples that can be reused and adapted across different projects.

## Contents
- Common SQL queries
- Table creation scripts (`CREATE TABLE`)
- Database schemas
- Primary and foreign key examples
- Constraints and indexes
- Views and other PostgreSQL examples

## Technology
- PostgreSQL
- SQL

## Status
Work in progress. Templates and examples will be added and organized progressively.

## Usage
The SQL scripts can be used as reference examples and adapted according to the requirements of each project.

## Notes
This repository is intended for learning, reference, and sharing reusable PostgreSQL SQL examples.
